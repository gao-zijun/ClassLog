🔐 ClassLog 根证书安装指南

ClassLog 使用自签名 SSL 证书（mkcert 生成），浏览器默认不信任它，会显示"不安全"警告。安装根证书后，即可正常访问，不再弹警告。

第一次怎么打开这个页面？

因为还没装证书，浏览器会拦截。请按下面操作强行进入一次：

  1. 在浏览器地址栏输入 https://10.1.2.41，回车。
  2. 出现"您的连接不是私密连接"页面，点击 「高级」。
  3. 点击 「继续前往 10.1.2.41（不安全）」。
  4. 此时就能看到本页面，下载证书并安装。
  5. 安装完成后，彻底关闭浏览器再重新打开，警告就消失了。

🪟 Windows 安装方法

  1. 下载 rootCA.crt。
  2. 双击该文件 → 点击「安装证书」。
  3. 存储位置选择 「当前用户」（推荐）或「本地计算机」。
  4. 点击「下一步」→ 选择 「将所有的证书都放入下列存储」。
  5. 点击「浏览」→ 选择 「受信任的根证书颁发机构」 → 确定。
  6. 一路「下一步」→「完成」→ 弹出安全警告点「是」。
  7. 重启浏览器生效。

🍎 macOS 安装方法

  1. 下载 rootCA.crt，双击打开，会自动导入「钥匙串访问」。
  2. 在「系统」或「登录」钥匙串中找到 mkcert development CA。
  3. 双击它 → 展开「信任」→ 将 「使用此证书时」 设为 「始终信任」。
  4. 关闭窗口，输入开机密码确认。
  5. 重启 Safari / Chrome 生效。

📱 iOS / iPadOS 安装方法

  1. 用 Safari 打开本页，点击下载 rootCA.crt。
  2. 弹出「此网站正尝试下载一个配置描述文件」→ 点击「允许」。
  3. 进入 设置 → 通用 → VPN与设备管理，找到已下载的描述文件，点击「安装」。
  4. 再进入 设置 → 通用 → 关于本机 → 证书信任设置。
  5. 找到 mkcert development CA，把开关 打开（信任）。
  6. 重启 Safari 生效。

🤖 Android 安装方法

  1. 下载 rootCA.crt（会存到「下载」文件夹）。
  2. 进入 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书。
  3. 弹出警告点「仍然安装」。
  4. 选择刚才下载的 rootCA.crt 文件。
  5. 系统会提示「已安装 CA 证书」。
  6. 注意：Chrome 等浏览器可能仍不信任用户安装的证书，建议使用系统自带浏览器或 Firefox 访问。

❓ 常见问题

  • 装完还是提示不安全？ → 彻底关闭浏览器（不是关标签页）再重新打开；Windows 上可运行 certmgr.msc 检查证书是否在「受信任的根证书颁发机构 → 证书」里。
  • 访问 IP 变了怎么办？ → 证书里已包含 127.0.0.1、10.1.2.41、localhost，换其他 IP 需要重新生成证书。
  • 证书到期了？ → 有效期至 2028-12-20，到期前联系管理员用 mkcert 重新签发。
  • 能不能不装证书？ → 可以，每次点「高级 → 继续前往」即可，但体验较差。
✅ 安装完成后，重新访问 https://10.1.2.41 或 https://127.0.0.1，地址栏会显示锁形图标，不再有警告。
